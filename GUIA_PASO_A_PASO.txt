FINANZAS v4 · GUÍA PASO A PASO
================================

No necesitas saber programar. No hay servicios de pago.

A. SUBIR LA ACTUALIZACIÓN A GITHUB
----------------------------------
1. Cierra Finanzas si la tienes abierta.
2. Descomprime Finanzas_v4.zip.
3. Abre tu carpeta del repositorio «finanzas» en el Explorador de archivos.
4. Copia dentro TODO lo que hay en la carpeta descomprimida.
5. Cuando Windows pregunte, pulsa «Reemplazar los archivos del destino».
6. Abre GitHub Desktop.
7. Arriba, comprueba que pone el repositorio «finanzas».
8. Abajo a la izquierda, en Summary, escribe: v4
9. Pulsa «Commit to main».
10. Pulsa «Push origin».
11. En github.com abre el repositorio → Actions. Espera a que «Prueba Finanzas» tenga un ✓ verde.
12. Vuelve a GitHub Desktop: pulsa «Fetch origin» y después «Pull origin». Esto trae el contexto y el mapa actualizados automáticamente.

B. ACTUALIZAR EL WORKER DE CLOUDFLARE (GRATIS)
------------------------------------------------
El Worker ya lo tienes. NO borres el KV, TOKEN ni las claves que ya funcionan.

1. Entra en https://dash.cloudflare.com e inicia sesión.
2. En el menú, pulsa «Workers & Pages».
3. Pulsa tu Worker «finanzas».
4. Pulsa «Edit code» o «Editar código».
5. En tu ordenador abre el archivo worker.js del ZIP con Bloc de notas.
6. Pulsa Ctrl+A y después Ctrl+C.
7. Vuelve al editor de Cloudflare. Pulsa dentro del código, Ctrl+A y Ctrl+V.
8. Pulsa «Deploy» o «Implementar».
9. Vuelve a Finanzas → Más → Ajustes → «Guardar y probar».
10. Debe poner «Worker conectado» y versión w2.

Protección recomendada (también gratis):
1. En Cloudflare abre tu Worker «finanzas».
2. Ve a Settings → Variables and Secrets.
3. Pulsa Add.
4. Tipo: Secret. Nombre: ALLOWED_ORIGIN.
5. Valor: la parte inicial de tu web, sin barra al final. Ejemplo: https://TU-USUARIO.github.io
6. Pulsa Deploy.
7. Vuelve a Finanzas y pulsa «Guardar y probar».
Si tu web deja de conectar, revisa que no hayas puesto /finanzas al final: debe ser solo https://TU-USUARIO.github.io

C. CONECTAR EXCHANGES CON APIS OFICIALES Y GRATIS
--------------------------------------------------
Conecta solo los que uses. Las claves deben ser SOLO LECTURA. Nunca marques operar, transferir o retirar.
En todos los casos, las claves se pegan en Cloudflare → Worker «finanzas» → Settings → Variables and Secrets → Add → Secret.

BINANCE
1. Entra en Binance desde el ordenador.
2. Perfil → Account → API Management (Gestión de API).
3. Crea una API «System generated».
4. Ponle el nombre «Finanzas lectura».
5. Deja activado únicamente «Enable Reading».
6. Copia API Key. En Cloudflare crea el secreto BINANCE_KEY y pega el valor.
7. Copia Secret Key. Crea BINANCE_SECRET y pega el valor.
8. No actives Spot Trading, Margin, Futures, Withdrawals ni Universal Transfer.

KRAKEN
1. Entra en Kraken.
2. Perfil → Settings → API → Create API key.
3. Nombre: «Finanzas lectura».
4. Marca solo permisos de consultar fondos, órdenes/operaciones y ledger.
5. No marques depositar, retirar ni modificar órdenes.
6. En Cloudflare crea KRAKEN_KEY con la API key.
7. Crea KRAKEN_SECRET con el private key/secret.

KUCOIN
1. Entra en KuCoin.
2. Perfil → API Management → Create API.
3. Nombre: «Finanzas lectura».
4. Permiso: General (lectura). No marques Trade ni Transfer.
5. Guarda también la passphrase que tú escribas.
6. En Cloudflare crea KUCOIN_KEY, KUCOIN_SECRET y KUCOIN_PASSPHRASE.

OKX
1. Entra en OKX.
2. Perfil → API → Create V5 API key.
3. Nombre: «Finanzas lectura».
4. Permiso: Read. No marques Trade ni Withdraw.
5. Guarda la passphrase.
6. En Cloudflare crea OKX_KEY, OKX_SECRET y OKX_PASSPHRASE.

BYBIT
1. Entra en Bybit.
2. Perfil → API → Create New Key.
3. Elige una clave creada por el sistema.
4. Marca «Read-Only».
5. En Cloudflare crea BYBIT_KEY y BYBIT_SECRET.
6. Si tu cuenta es de la web europea y aparece un error de región, crea también BYBIT_BASE con el valor https://api.bybit.eu. Si la propia cuenta europea no permite una clave personal de lectura, usa la importación de extracto; no contrates nada.

Al terminar: Finanzas → Ajustes → «Guardar y probar». El exchange conectado debe salir con ✓. La primera actualización puede tardar unos segundos.

D. BANCOS Y BRÓKERES SIN API PERSONAL GRATUITA
-----------------------------------------------
No se usa ningún agregador de pago. Para Santander, MyInvestor y cualquier entidad que no dé una API personal oficial y gratuita:

1. Entra en la web o app del banco/bróker.
2. Busca Movimientos, Actividad, Historial o Extractos.
3. Pulsa Descargar o Exportar.
4. Elige CSV, Excel/XLSX, OFX, QFX o QIF.
5. En Finanzas pulsa Importar y elige el archivo.
6. Si el formato no se reconoce, aparece «Elegir columnas».
7. Elige uno de estos tipos:
   - Movimientos de banco o tarjeta.
   - Operaciones de inversión o cripto.
   - Posiciones actuales (si solo tienes un listado de tu cartera).
8. Relaciona Fecha, Concepto/Activo e Importe/Cantidad.
9. Pulsa Seguir e Importar.

Puedes repetir periodos que se solapen: la app ignora duplicados. Un snapshot enseña tu cartera, pero para impuestos necesitas el historial de compras, ventas y comisiones.

E. GRÁFICOS DE ACTIVOS
----------------------
TradingView es gratuito y no necesita cuenta ni clave.
1. Abre Finanzas → Inversiones.
2. Toca cualquier activo.
3. El gráfico aparece dentro de la ficha.
4. Si sale otro activo o no carga: abre «Ajustar activo y símbolo».
5. En «Símbolo de TradingView» escribe el mercado y el símbolo. Ejemplos:
   - BINANCE:BTCUSDT
   - NASDAQ:AAPL
   - BME:IBE
   - XETR:VWCE
6. Pulsa Guardar y vuelve a abrir el activo.

El gráfico es una ayuda visual. Los saldos y costes los calcula Finanzas con tus datos, no TradingView.

F. COMPROBAR MÓVIL Y PORTÁTIL
------------------------------
1. Portátil: abre Inicio. Debes ver el panel completo con barra lateral.
2. Móvil: cierra y vuelve a abrir la PWA. Debes ver un inicio más corto y cuatro pestañas abajo.
3. Pulsa ☰ arriba a la izquierda: debe abrirse el menú lateral.
4. Haz un cambio en el móvil. Espera unos segundos y abre el portátil.
5. En ambos, el estado debe decir «Sincronizado».
6. Comprueba modo claro, oscuro y el botón para ocultar importes.

Si ves la versión antigua:
1. Cierra por completo la app.
2. Abre de nuevo con internet.
3. Si sigue igual, en el navegador borra solo la caché del sitio, NO los datos del sitio.
